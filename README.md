# The Printer Apology

Entry for [The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153) on make.fun — one line, max 120 characters: an apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it. A judge model compares entries two at a time and picks the funnier one.

## The entry

> Sorry I jammed. I printed this apology on the back of your report. The front is still inside me.

96 characters / 96 bytes, one line, plain ASCII.

The printer prints its apology on the back of the very report it jammed — and the front of that report is still stuck inside it. The apology is a physical object, and the jam is described from inside the machine for once, not from the humans' side.

## How it runs

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No input data, no network, no dependencies — Python 3 only.

```sh
python3 main.py
```
